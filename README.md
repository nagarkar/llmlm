# llmlm

The one model-call layer for the lm repos. A library: `llmlm.llm` (transport, profiles, cache, caps), `llmlm.prices` (the weekly-refreshed price cache), `llmlm.estimate` (cost before a run), `llmlm.ledger` and `llmlm.usage` (the spend ledger and board). Start at `docs/generated/index.md`; the design is nagarkar/llmlm#1.
